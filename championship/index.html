The Arcade Championship

Every game in the arcade feeds one table. Finish a game and you earn 5 points. Medals earn more: bronze 10, silver 20, gold 30, and a Wren medal 50. Solving a game's daily-seed case earns 3. The table never resets — it is the long game the weekly games hang on.

For now, this table is kept in your own browser, on this machine — your points, honestly come by. Shared tables, where everyone can see everyone, arrive when the arcade's score service opens.

Each game's own board

Alongside the championship, every game keeps its own leaderboard — a shift score in The Night Log, and whatever each future game measures. A game's board closes when the game goes into the Vault, and the final table stays on its page for good.
